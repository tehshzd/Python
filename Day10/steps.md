# Steps Involved in Data Wrangling

1. **Gathering Data**

2. **Assessing the Data (Exploratory Data Analysis – EDA)**

3. **Cleaning the Data**
   1. Dealing with missing values.
   2. Correcting errors and inconsistencies in the data.
   3. Detecting and handling outliers:
      - Visualization (Boxplot, Histogram, etc.)
      - IQR Method
      - Z-score Method
   4. Removing duplicate records.

4. **Transforming the Data (Data Transformation and Scaling)**
   1. Min-Max Normalization / Scaling
   2. Standard Scaling
   3. Winsorization
   4. Log Transformation
   5. Z-score Standardization
   6. Decimal Scaling

5. **Feature Engineering**
   - Creating new features from existing columns.
   - Encoding categorical variables.
   - Extracting useful information from existing features.

6. **Organizing the Data**
   1. Creating new columns.
   2. Renaming columns.
   3. Rearranging columns.
   4. Changing data types where necessary.

7. **Saving the Wrangled Data**
   - Saving the cleaned and transformed dataset for further analysis or machine learning.
